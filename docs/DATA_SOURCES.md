# Data Sources

The cleaned master dataset was compiled from public government data sources.

## Fecal-indicator-bacteria observations

California Open Data Portal. Surface Water Fecal Indicator Bacteria Monitoring Results.

Primary dataset page:
https://data.ca.gov/dataset/surface-water-fecal-indicator-bacteria-results

Resource used in earlier downloads:
https://data.ca.gov/dataset/surface-water-fecal-indicator-bacteria-results/resource/15a63495-8d9f-4a49-b43a-3092ef3106b9

## Weather data

NOAA/NCEI Global Historical Climatology Network Daily Summaries.

Product page:
https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily

NOAA Climate Data Online:
https://www.ncei.noaa.gov/cdo-web/

## Notes

Earlier exploratory versions considered tide and sanitary sewer overflow variables. The final selected analysis uses no-tides/no-SSO feature sets.
